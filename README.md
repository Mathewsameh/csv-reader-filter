# CSV Reader & Filter 🐍

A Python project to read, search, filter, add, and delete student records stored in a CSV file.

## Features

- Read student records.
- Search for students.
- Filter student data.
- Add new student records.
- Delete student records.
- Store data in a file.

## Technologies Used

- Python
- CSV Files
- Jupyter Notebook

## Project Files

- `CSV Reader & Filter.ipynb` — Contains the Python code.
- `students.csv` — Contains sample student records.

## How to Run

1. Download the project files.
2. Open the notebook using Jupyter Notebook.
3. Make sure the data file is in the same folder as the notebook.
4. Run the notebook cells.
